# P06 - Atelier 1 React

Projet complet basé sur l'atelier du document **Développer en Front-End - Partie N°6 – Incorporer les styles et les assets**.

## Ce qui est inclus

- `className` dans les composants React.
- `Banner.css` avec les classes `lmj-banner`, `lmj-title` et `lmj-logo`.
- Import d'un asset `logo.png` dans `Banner`.
- `Cart.css` avec la classe `lmj-cart` demandée par l'atelier :
  - `padding: 32px`
  - texte blanc
  - `background-color: #31b572`
- Application de `lmj-cart` au composant `Cart`.

## Lancer le projet

Prérequis : Node.js installé.

```bash
npm install
npm start
```

Puis ouvrir l'adresse affichée par Vite dans le terminal.
